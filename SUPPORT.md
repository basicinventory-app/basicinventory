# Support

Support for BasicInventory happens **here on GitHub**, in the open, so that an
answer helps the next person with the same question.

There is no support email. Everything technical is handled in this repository;
anything tied to your purchase is handled where you bought the licence, which
keeps it attached to your order.

## Where to go

| I want to… | Go to | Why there |
| --- | --- | --- |
| Report something broken | [Bug report](https://github.com/basicinventory-app/basicinventory/issues/new?template=bug_report.yml) | It becomes a tracked issue with a version and steps. |
| Ask for a new feature | [Feature request](https://github.com/basicinventory-app/basicinventory/issues/new?template=feature_request.yml) | It can be labelled and linked to a milestone. |
| Ask how to do something | [Discussions → Q&A](https://github.com/basicinventory-app/basicinventory/discussions/categories/q-a) | Conversations, not tickets — and answers stay searchable. |
| Share an idea before formalising it | [Discussions → Ideas](https://github.com/basicinventory-app/basicinventory/discussions/categories/ideas) | Other users can weigh in first. |
| Report a security vulnerability | [Private report](https://github.com/basicinventory-app/basicinventory/security/advisories/new) | Private between you and the maintainer. **Never a public issue** — see [SECURITY.md](SECURITY.md). |
| Ask about a purchase, an invoice, a refund or a licence | The [Microsoft Store](https://apps.microsoft.com/detail/9N8GQS365ZLM) | Your order details are there, and Microsoft handles purchases and refunds under its own policy. |

Not sure? Open a Q&A discussion. It gets converted to an issue if it turns out
to be a bug.

### Purchases and licensing

BasicInventory is sold on the
[Microsoft Store](https://apps.microsoft.com/detail/9N8GQS365ZLM), which is the
only place to buy and install it. Anything about a purchase, refund or invoice
goes through Microsoft's own purchase and refund support, which keeps it attached
to your order. See [How to get BasicInventory](docs/microsoft-store.md).

The licence is your Store purchase, tied to your Microsoft account — there is no
key to activate. Nothing about a purchase belongs in a public issue: order
numbers, invoices and addresses stay off this repository.

## Before you write

Nine out of ten reports are answered faster when they arrive complete:

1. **Check your version.** Settings → Errors and diagnostics shows it. Windows
   keeps the Store copy up to date, so make sure you are on the current version
   (**Microsoft Store → Library → Get updates**) — the problem may already be
   fixed. See the [changelog](CHANGELOG.md).
2. **Search** [existing issues](https://github.com/basicinventory-app/basicinventory/issues?q=is%3Aissue)
   and [discussions](https://github.com/basicinventory-app/basicinventory/discussions).
   Adding "same here" plus your details to an open issue is more useful than a
   duplicate.
3. **Collect the diagnostics.** In the app: **Settings → Errors and diagnostics →
   Copy diagnostics**. It carries the version, your Windows details and the last
   errors, with your Windows user name stripped from the paths. Paste it into the
   report.
4. **Say what you expected.** "It does not work" cannot be reproduced; "after
   registering an exit of 5 units the stock still shows 20" can.

## Response times

This is a small operation, so honest expectations:

| | Typical first response |
| --- | --- |
| Security reports | Within 48 hours |
| Bugs that block work (data loss, will not start) | 1–2 working days |
| Other bugs | Within a week |
| Feature requests | Reviewed in batches, roughly monthly |
| Questions in Discussions | When someone gets to them — often the community first |

Weekends and holidays excluded. A quiet issue is not an ignored issue; it is
usually queued behind something that broke.

## What is supported

- The **latest released version**, on **Windows 10 and 11 (64-bit)**.
- The previous minor version receives security and critical fixes only.
- Modified installations, unofficial builds and unsupported operating systems
  cannot be supported.

## Please do not

- Post licence keys, invoices or personal data in a public issue.
- Attach a database backup publicly — it contains your business data. If a file
  is needed to diagnose something, you will be asked for it privately.
